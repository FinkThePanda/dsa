# Green: topic notes

An array supports indexing. A linked list connects nodes through references; reaching position i requires walking the links. A stack uses last-in-first-out order; a queue uses first-in-first-out. A circular array queue reuses freed slots without shifting elements. Binary search keeps an invariant describing the remaining candidates.
