# Gold: topic notes

Segment trees aggregate intervals, allowing point updates and range queries in O(log n). Union Find maintains component roots; path compression and union by rank/size yield amortized O(alpha(n)) operations, with O(n) initialization. Topological sorting orders a directed acyclic graph; a cycle prevents an ordering. Hard DP often needs more than one state dimension.

For Edit Distance, draw a prefix table and identify insertion/deletion/replacement transitions. For Alien Dictionary, derive edges only from the first mismatch of neighboring words. For N-Queens, track columns and diagonals. For rain water, begin with left/right maximum arrays before trying two pointers.
