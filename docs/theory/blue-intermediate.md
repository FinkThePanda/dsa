# Blue: topic notes

A hash map connects keys to values; a set tracks membership. Trees connect a root to children. DFS follows a branch before backtracking; BFS uses a queue to visit by distance in an unweighted graph. A heap exposes the smallest priority efficiently: enqueue/dequeue are O(log n).

Use Dictionary for complement lookup in Two Sum. Mark visited cells in island traversal to avoid repeats. C# PriorityQueue is a min-heap, so selecting the most frequent items requires deliberate priorities. Deep recursive DFS may exhaust the stack; consider iterative traversal.
